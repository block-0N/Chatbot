核心功能

从问答到推理，从对话到技能，一应俱全

💬

智能问答匹配

精确匹配、模糊纠错、关键词评分、多关键词组合推理，四层匹配策略层层递进。

📖

文章自动抽取

粘贴一整段文章，自动识别"X是Y""X属于Y"等句式，生成问答对。

🧠

上下文联想

记住最近 3 个话题，支持"它喜欢吃什么"这类代词指代。

🎓

主动学习

未命中时反问"要不要教我"，用户一句话就能教会新知识。

⚙️

配置外置

同义词、停用词、关系词等 10 份配置文件，改完 /reload 生效，无需重编译。

🇨🇳

完整中文支持

基于 Windows API 的宽字符读取，无论控制台代码页如何，中文输入输出都正常。

快速开始

下载即用，无需配置

1

下载安装包

从 Releases 下载 Chatbot_v2.0_Setup.exe，双击安装。

2

启动程序

从开始菜单或桌面快捷方式启动，无需联网，无需安装任何依赖。

3

开始对话

选择模式 3 进入对话，或选模式 1 训练新知识。

# 主菜单 1. 对话训练 格式：问题|回答 2. 文章训练 粘贴文章自动抽取 3. 对话模式 和机器人聊天 4. 退出 5. 词库管理 # 对话内命令 /debug 开关调试输出 /reload 重载配置 /forget 删除知识 /import 批量导入 /export 导出知识库
