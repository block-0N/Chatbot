## 模式一：对话训练

逐条教机器人新知识。

### 格式

```
问题|回答
```

### 示例

```
你好|你好呀，很高兴见到你
你是谁|我是一个离线聊天机器人
苹果是什么|苹果是一种常见的水果
```

### 说明

- 分隔符是**半角竖线 `|`**（不是全角 `｜`）。
- 问题会被自动归一化（去空格标点、中文标点转英文、同义词替换）。
- **同一问题可以训练多个回答**，机器人会轮流返回。
- 每训练一条会自动保存。

### 批量导入

准备 `data.txt`，每行 `问题|回答`：

```
你好|你好呀
你是谁|离线聊天机器人
苹果是什么|苹果是水果
```

然后：

```
/import data.txt
```

## 模式二：文章训练

粘贴一整段文章，机器人自动抽取知识。

### 使用流程

1. 进入文章模式。
2. 粘贴文章内容（可多行）。
3. **按 Ctrl+Z 再回车**结束输入（或输入 `/end`）。
4. 程序预览抽取结果。
5. 输入 `y` 确认训练，或 `n` 取消。

### 支持的关系句式

| 句式 | 示例 | 生成问答 |
|---|---|---|
| X是Y | 猫是一种哺乳动物 | 猫是什么？\|猫是一种哺乳动物 |
| X属于Y | 狗属于犬科动物 | 狗属于什么？\|狗属于犬科动物 |
| X包括Y | 水果包括苹果、香蕉 | 水果包括什么？\|水果包括苹果、香蕉 |
| X喜欢Y | 猫喜欢鱼 | 猫喜欢什么？\|猫喜欢鱼 |
| X会Y | 鸟会飞 | 鸟会什么？\|鸟会飞 |
| X需要Y | 宠物需要打疫苗 | 宠物需要什么？\|宠物需要打疫苗 |
| X位于Y | 北京位于中国北方 | 北京位于哪里？\|北京位于中国北方 |
| X被称为Y | 老虎被称为百兽之王 | 老虎叫什么？\|老虎被称为百兽之王 |
| 因为X所以Y | 因为下雨，所以延期 | 为什么延期？\|因为下雨，所以延期 |

### 正向与反向生成

- **正向**：`猫喜欢鱼` → `猫喜欢什么？`
- **反向**：`猫喜欢鱼` → `谁喜欢鱼？`（模板支持时才生成）

### 预览示例

```
[预览] 扫描句子: 18，命中: 11，生成: 17，去重跳过: 0
将训练以下 17 条（前 10 条）：
  1. 猫是什么？ | 猫是一种哺乳动物
  2. 什么是哺乳动物？ | 猫是一种哺乳动物
  ...
确认训练？(y/n):
```

### 统计报告

训练完成后显示：

```
[报告] 实际训练: 10，新增问题: 6，新增变体: 4
```

- **新增问题**：知识库里没有的新问题
- **新增变体**：已存在的问题，追加了新回答

## 模式三：对话

和机器人正常聊天。

### 匹配优先级

用户输入会依次尝试以下路径，命中即返回：

1. **内置技能**（计算器、时间、骰子等）
2. **精确匹配**（知识库里有完全一样的问题）
3. **上下文代词**（"它喜欢吃什么" → 解析为上一次的话题）
4. **模糊纠错**（"苹果是什" → "苹果是什么"）
5. **关键词评分**（分词后按词匹配打分）
6. **多关键词推理**（多个关键词命中同一问题）
7. **主动学习**（未命中时反问"要不要教我"）

### 回答前缀说明

| 前缀 | 含义 |
|---|---|
| （无） | 精确匹配或关键词命中 |
| `[已为你修正输入]` | 走了模糊纠错 |
| `[上下文·延续]` | 代词替换到了上一话题 |
| `[推理匹配]` | 多关键词组合推理 |
| `[技能名]` | 命中内置技能（如 `[计算]`） |

### 候选列表

当多个候选得分接近时，会列出前 3 条：

```
> 苹果
AI: 我想到多个相关内容：
  · 苹果是什么：苹果是一种常见的水果
  · 苹果好吃吗：苹果口感脆甜
  · 苹果派是什么：苹果派是一种烘焙甜点
你可以再具体一点，或直接问其中一个。
```

### 上下文联想

机器人记住最近 3 个话题，支持代词指代：

```
> 猫是什么
AI: 猫是一种哺乳动物

> 它喜欢吃什么
AI: [上下文·延续] 猫喜欢吃鱼和猫粮
```

### 主动学习

输入未命中时：

```
> 苹果派是什么
AI: 我没学过"苹果派是什么"，要不要教我？
    直接输入答案，或输入 skip 跳过。

> 苹果派是一种烘焙甜点
AI: 学会了！以后你问"苹果派是什么"我就知道。
```

- 输入 `skip` 或空行可跳过。
- 跳过的问题会记住，最近 20 条内不再问。

## 文件说明

| 文件 | 作用 | 是否必需 |
|---|---|---|
| `functions.exe` | 主程序 | 是 |
| `dict.dat` | 中文词典，每行一个词，用于分词 | 推荐提供 |
| `data.dat` | 知识库（自动生成） | 自动创建 |
| `data.dat.tmp` | 保存时的临时文件 | 自动管理 |

### `dict.dat` 格式

```
苹果
香蕉
橙子
...
```

每行一个词，UTF-8 编码。没有也能运行，但分词效果会变差（退化为单字）。

### `data.dat` 说明

- 是**二进制安全**的自定义文本格式。
- 用长度前缀记录每条问题和回答，能存任意字符。
- 保存时先写 `.tmp` 再原子替换，避免崩溃损坏。
- 加载时"尽力读取、读不动就停"，损坏时保留能读的部分。

## 常见问题

### Q1：程序提示"未找到 dict.dat"怎么办？

不影响运行，但分词会退化为按单字切分，匹配准确度下降。建议下载一份中文常用词表（每行一词）保存为 `dict.dat`。

### Q2：训练后问题不命中？

检查：

1. `/debug` 打开调试，看关键词评分 Top5。
2. 输入和问题的归一化形式是否一致（去掉了空格标点）。
3. 是否被模糊纠错到了别的问题。

### Q3：同一问题多次回答不一样？

正常行为。同一问题有多个回答时会**按顺序轮换**返回，方便提供多样化回答。

### Q4：导入 0 条记录？

检查：

- 文件是否为空。
- 分隔符是否为**半角 `|`**（不是全角 `｜`）。
- 编码是否为 UTF-8（无 BOM）。
- 每行是否都有 `问题|回答` 两部分。

### Q5：文章训练抽不到知识？

检查句式是否匹配支持的关系词。当前支持：是、属于、包括、喜欢、会、需要、位于、被称为、因为…所以…

### Q6：倒计时怎么没提醒？

倒计时是**协作式**的：程序在每次等待用户输入前才检查。如果一直不输入，就不会提醒。到时后下一次输入时才会看到提示。

### Q7：技能和知识库冲突怎么办？

技能**优先于**知识库。比如训练过 `几点|早上八点`，输入 `几点` 仍会走时间技能。如果想让知识库优先，可以改问题的措辞（比如训练成 `几点上班|早上八点`）。

### Q8：怎么备份知识库？

两种方式：

- 直接复制 `data.dat` 文件。
- `/export backup.txt` 导出为可读文本。

### Q9：知识库乱了想重置？

关闭程序，删除 `data.dat`，重新启动即可。或先用 `/export` 导出，然后按需整理。

### Q10：如何看机器人"怎么想的"？

```
/debug
```

打开后每次匹配会打印：

- 技能命中情况
- 纠错命中详情（距离、比例）
- 关键词评分 Top5
- 推理关键词和命中数
- 是否走兜底

关闭再输入一次 `/debug` 即可。

## 小技巧

1. **多问几次同一问题**，可以看到该问题的所有回答变体。
2. **主动学习时输入 skip**，避免被反复追问同一个问题。
3. **文章训练前先 `/export` 备份**，抽错了可以用 `/forget` 清理。
4. **同义句多训练几条**，比如 `苹果是什么` 和 `苹果是啥` 都教一遍，召回更稳。
5. **技能和知识库结合**，比如用文章模式把百科知识批量导入，用技能补充动态内容。
